# 🏦 Bank Management System

A simple **Bank Management System** built using **Python and Streamlit**.

This project allows users to create bank accounts, deposit and withdraw money, view account details, update information, and delete accounts through an easy-to-use web interface.

## 🚀 Features

* Create New Bank Account
* Deposit Money
* Withdraw Money
* Show Account Details
* Update Account Information
* Change PIN
* Delete Account
* Simple and User-Friendly Interface

## 🛠️ Technologies Used

* Python
* Streamlit

## ⚙️ Installation

First, install Streamlit:

```bash
pip install streamlit
```

## ▶️ Run the Project

Open the project folder in Terminal or PowerShell:

```bash
cd "Bank-Management-main"
```

Then run:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🏦 Available Options

### 1. Create Account

Enter:

* Name
* Age
* Email
* 4-digit PIN

The system creates a new account and generates an account number.

### 2. Deposit

Enter your:

* Account Number
* PIN
* Amount

Then click **Deposit**.

### 3. Withdraw

Enter your:

* Account Number
* PIN
* Amount

Then click **Withdraw**.

### 4. Show Details

Enter your account number and PIN to view your account information.

### 5. Update Info

You can update:

* Name
* Email
* PIN

### 6. Delete Account

Enter your account number and PIN to delete the account.

## 🎯 Project Objective

The main objective of this project is to create a simple banking application using Python programming concepts and Streamlit. It demonstrates basic account management and banking operations through a web-based interface.
